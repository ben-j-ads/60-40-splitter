# The 60/40 Splitter

A starting point for splitting a budget between long-term brand building and short-term activation, based on the Binet & Field long-and-short rule.

Open `index.html` in any browser. No build step and no dependencies.

- **Starting point:** 60% brand, 40% activation.
- **Adjustments:** each input moves the brand share by 10 points.
  - Purchase cycle: months or years → toward brand; days → toward activation.
  - Brand size: startup or challenger → toward brand; established leader → toward activation.
  - Price tier: premium → toward brand; value → toward activation.
  - Weeks and mainstream are neutral.
- **Limits:** brand share stays between 30% and 85%.

60/40 is a cross-category average from the IPA Databank. This is a starting heuristic, not a media plan.
